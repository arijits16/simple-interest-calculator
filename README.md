
# Simple Interest Calculator

A Bash-based calculator that computes simple interest using the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Annual rate of interest (%)
- Time period in years

## Output
- Calculated simple interest

## How to Run

```bash
bash simple-interest.sh
```
